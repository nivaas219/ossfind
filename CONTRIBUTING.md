# Contributing to ossfind

Thanks for your interest in contributing to ossfind! 🎉

We welcome contributions from everyone. Whether you are fixing bugs, improving documentation, or adding new features, your help is appreciated.

## Ways to contribute

You can help by:

- Adding new open source swag programs
- Improving issue discovery
- Fixing bugs
- Improving documentation
- Suggesting new features

## How to contribute

### 1. Fork the repository

Fork this repository to your GitHub account.

### 2. Create a new branch
```bash
git checkout -b your-feature-name
```

### 3. Make your changes

Implement your feature, fix, or improvement.

### 4. Test your changes

Make sure the project works correctly before submitting your Pull Request.

### 5. Submit a Pull Request

Create a Pull Request with:

A clear title
Description of your changes
Any testing details

### Good First Issues

New to open source?

Look for issues labeled:

good first issue
help wanted

These are beginner-friendly tasks.

### Code Style

Please keep changes:

Simple and focused
Easy to understand
Consistent with the existing code style

### Need Help?

If you have questions or need guidance, feel free to open an issue.

Thank you for helping improve ossfind! 🚀
