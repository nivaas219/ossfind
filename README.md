🚀 Stop searching GitHub manually.
Find beginner-friendly open source issues and contributor programs from your terminal.

## Installation

```bash
pip install ossfind
Usage
Find good first issues
# Find all good first issues
ossfind find

# Filter by language
ossfind find --language python

# Filter by repo
ossfind find --repo mattermost/mattermost

# Limit results
ossfind find --limit 5
Find swag programs
# List all swag programs
ossfind swag

# Filter by difficulty
ossfind swag --difficulty easy
ossfind swag --difficulty medium
ossfind swag --difficulty hard
